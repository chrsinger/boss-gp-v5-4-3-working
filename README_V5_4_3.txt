BOSS GP Scrutineering V5.4.3 – GitHub Pages PWA

Upload index.html, sw.js, manifest.webmanifest and icons/ to a NEW public GitHub Pages repository. Never upload private JSON master data or backups.

Changes since V5.4.2:
- Current Event / Previous Events / All Findings views with status filters.
- Unresolved previous-event findings are associated by chassis and highlighted at Initial Scrutineering.
- Historical findings can be resolved at a later event without overwriting the original inspection status.
- Event entries can be edited, added or removed/withdrawn, preserving master records and existing findings.
- Linked current-event findings can be marked resolved from the inspection or from Findings.
- More compact official A4 report layout, with live Initial Scrutineering summary and consistent signature/footer.

Important: Back up your data in V5.4.2 before moving to this new GitHub Pages origin. Each Pages repository uses separate browser storage. Import your private backup into V5.4.3 via Backup / Export. Do not upload the backup to GitHub.

PDF printing: In browser print settings disable headers and footers (URL, print date, browser page numbers). Verify the PDF before forwarding.

Validation: JavaScript syntax checked. No full iPad Safari or live GitHub Pages validation performed. Test on iPad with a backup before operational use.
